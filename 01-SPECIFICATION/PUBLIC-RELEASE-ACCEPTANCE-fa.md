# دروازهٔ پذیرش و انتشار عمومی N.U Driver

**شناسه:** NUD-PACK-PUBLIC-RELEASE-001  
**وضعیت:** دستور انتشار از مسیر خصوصی به عمومی؛ هیچ Release فعالی با این سند ایجاد نمی‌شود.

## 1. اصل

این مخزن ویترین و محل دانلود کاربران است، نه محل جمع‌آوری کاندیدها. فقط artifact نهایی که در Private Packaging آماده و مجوز انتشار آن ثبت شده است وارد این مخزن می‌شود.

## 2. ورودی اجباری

برای هر انتشار باید موارد زیر از مخزن خصوصی دریافت شوند:

- شناسه و نسخهٔ یکتای بسته
- لینک source repository و commit SHA دقیق
- manifest نهایی و dependencyها
- artifact و SHA-256/اندازه
- نتایج تست ماشینی و logهای مرتبط
- وضعیت QA انسانی و تأیید مالک
- مجوز انتشار کد و تمام assetها
- وضعیت امضای ناشر و دستور انتشار
- راهنمای نصب/ارتقا/حذف و ماتریس سازگاری

## 3. Gate انتشار

انتشار عمومی فقط وقتی مجاز است که همهٔ موارد مرتبط PASS باشند:

1. artifact دقیق از نسخهٔ خصوصی نهایی دریافت شده باشد.
2. SHA-256 قبل و بعد از انتقال یکسان باشد.
3. manifest با artifact و نسخه مطابقت داشته باشد.
4. تست‌های ضروری اجرا و نتیجه/محدودیت‌ها ثبت شده باشد.
5. امنیت، امضا، مجوز کد و مجوز assetها بررسی شده باشد.
6. راهنمای نصب و هشدارهای سازگاری کامل باشد.
7. QA انسانی و پذیرش مالک برای همان build ثبت شده باشد، هرجا در چرخهٔ پروژه لازم است.
8. دستور صریح انتشار همان نسخه ثبت شده باشد.

## 4. انتشار و دانلود

- هر نسخه باید GitHub Release مستقل با tag نسخه‌دار و فایل‌های دانلودی روشن داشته باشد.
- Release باید checksum و manifest عمومی منتشر کند.
- README باید لینک مستقیم به Releases و راهنمای نصب را پس از ایجاد اولین نسخه اضافه کند.
- هر نسخه باید immutable و قابل ردیابی به commit منبع و رکورد بستهٔ خصوصی باشد.
- اصلاح artifact منتشرشده با بازنویسی خاموش ممنوع است؛ نسخهٔ جدید با changelog و شمارهٔ نسخهٔ مناسب ساخته شود.

## 5. رد انتشار

اگر هر gate ناموفق یا نامشخص باشد، بسته منتشر نمی‌شود و به Private Packaging برای تکمیل/اصلاح برمی‌گردد. این مخزن نباید نسخهٔ ناقص را به‌عنوان دانلود رسمی نشان دهد.

## 6. وضعیت فعلی

در زمان ثبت این سند، Release و artifact عمومی وجود ندارد. منبع Native Runtime Gen 1 در مخزن اصلی هنوز PR باز و Draft دارد؛ installer، امضای تولیدی، payload بازی‌ها و تأیید واقعی پلتفرم کامل نیستند. بنابراین اولین انتشار عمومی هنوز مجاز/آماده نیست.
