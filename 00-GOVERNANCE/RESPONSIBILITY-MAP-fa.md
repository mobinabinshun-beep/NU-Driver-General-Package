# نقشه مسئولیت — NU-Driver-General-Package

## وضعیت
PROPOSED — مخزن در زمان ممیزی خالی بوده است؛ این سند یک پیشنهاد سازمانی است، نه توصیف قابلیت موجود.

## مسئولیت اصلی پیشنهادی
توزیع عمومی و قابل استفاده مجدد N.U Driver و قراردادهای عمومی آن.

## ورودی‌ها
- کد و artifact از مخزن تولیدکننده اصلی Driver (هنوز مشخص نشده).
- تصمیم‌های API و سازگاری مصوب.
- پروتکل‌های مصوب امنیت، نسخه‌بندی، کیفیت و انتشار.

## خروجی‌ها
- بسته عمومی نسخه‌دار (پس از ایجاد محتوای واقعی).
- مستندات نصب، استفاده، پیکربندی و ارتقا.
- نمونه‌های عمومی غیرمحرمانه.
- ماتریس سازگاری و گزارش آزمون.

## مرز با بسته خصوصی
مخزن عمومی مرجع محتوای قابل انتشار است. هر چیزی که شامل credential، تنظیم داخلی، داده کاربر یا artifact محدودشده باشد خارج از این مخزن است. بسته خصوصی می‌تواند از قرارداد عمومی استفاده کند اما نباید بدون ثبت تغییر، قرارداد متفاوتی معرفی کند.

## کنترل‌های پیشنهادی
1. هر نسخه به commit و manifest دقیق متصل باشد.
2. تغییر ناسازگار API نیازمند نسخه‌گذاری و راهنمای مهاجرت باشد.
3. انتشار عمومی فقط پس از آزمون، بازبینی و تأیید مالک انجام شود.
4. نمونه‌ها نباید شامل secret یا اطلاعات واقعی حساس باشند.
5. منبع واقعی کد Driver و مجوز انتشار باید پیش از افزودن کد روشن شود.

## موارد نامشخص
- مخزن منبع کد Driver
- مالک فنی و نگهدارنده بسته
- زبان/پلتفرم و قالب بسته
- API عمومی و سطح پشتیبانی
- مجوز انتشار و چرخه انتشار
- رابطه دقیق با بسته خصوصی

هیچ کد، workflow، انتشار یا gate در این مرحله فعال نشده است.
